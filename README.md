# ETG Timer Assistant – Downloads

Hier liegen die fertigen Fassungen des ETG Timer Assistant. Die App holt sich neue Fassungen von hier selbst.

Die aktuelle Fassung findest du unter [Releases](https://github.com/AIMastergermany/etg-timer-assistant-releases/releases/latest).

- Mac (Apple-Chips): `ETG-Timer-Assistant-mac-arm64.dmg` laden, öffnen, die App nach „Programme“ ziehen.
- Windows (64 Bit): die Datei `…-win-x64-Setup.exe` der aktuellen Fassung laden und ausführen.

Der ETG Timer Assistant ist ein Zusatz zur ETG-App: https://app.easytogrowki.de
